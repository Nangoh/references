# 04. 레이아웃

## 앱 셸

모든 시스템은 같은 뼈대를 쓴다. 이 뼈대가 "같은 회사" 인상의 절반이다.

```
┌──────────────────────────────────────────────┐  .ds-shell__header  48px, --shell-bg (항상 어둡다)
│ 브랜드   대시보드  승인  설정          테마 홍길동 │
├────────┬─────────────────────────────────────┤
│ 사이드바 │ .ds-main                             │
│ 240px  │   .ds-page-header (제목 + 액션)        │
│        │   .ds-filter-row (한 줄)               │
│ .ds-   │   .ds-kpi-row                         │
│ sidebar│   .ds-card … .ds-card                 │
└────────┴─────────────────────────────────────┘
```

| 영역 | 클래스 | 크기 토큰 | 규칙 |
|---|---|---|---|
| 헤더 | `.ds-shell__header` | `--shell-h` 48px | 좌: 브랜드(시스템명), 중: 1차 메뉴, 우: 테마 토글·사용자. 페이지 제목은 여기 두지 않는다 |
| 사이드바 | `.ds-sidebar` | `--sidebar-w` 240px, 접힘 56px | 2차 메뉴. 메뉴가 5개 미만이면 생략 가능 |
| 본문 | `.ds-main` | `--content-max` 1440px | 좌우 패딩 `--sp-6`, 세로 간격 `--sp-6` |
| 페이지 제목 행 | `.ds-page-header` | | 좌 제목(`.ds-page-title`, 20px), 우 액션 버튼 1–3개. 주 버튼은 하나만 |

`body`에 `ds-shell`을 붙이면 CSS grid가 세 영역을 배치한다. 사이드바가 없으면 `.ds-sidebar`를 빼면 된다.

## 간격

4px 그리드. 간격은 `gap`으로 주고, 요소별 `margin`은 쓰지 않는다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--sp-1` | 4 | 아이콘과 글자 사이, 배지 안 |
| `--sp-2` | 8 | 버튼 사이, 칩 사이, 표 셀 안 세로 |
| `--sp-3` | 12 | 카드 안 요소 사이, 폼 필드 사이 |
| `--sp-4` | 16 | 카드 패딩, 표 셀 가로 |
| `--sp-6` | 24 | 카드 사이, 섹션 사이, 본문 패딩 |
| `--sp-8` | 32 | 큰 섹션 사이 |

레이아웃 유틸: `.ds-stack`(세로 gap `--sp-3`), `.ds-row`(가로 gap `--sp-2`, 세로 중앙), `.ds-grid`(`style="--cols:3"`, gap `--sp-4`, 720px 이하 1열).

## 밀도

| 항목 | 값 |
|---|---|
| 컨트롤(버튼, 입력, 셀렉트) 높이 | `--control-h` 32px, 큰 버전 40px |
| 표 행 높이 | 36px, compact 32px |
| 카드 패딩 | 16px |
| 사이드바 항목 높이 | 32px |
| 아이콘 | 16px, `currentColor` |

## 페이지 템플릿 5종

| 템플릿 | 구성 | 예시 |
|---|---|---|
| **목록** | 페이지 제목 + 주 버튼 → 필터 행 → (KPI 행 선택) → 표 카드 → 페이지네이션 | 승인 대기, 주문 목록 |
| **상세** | 제목 행(뒤로, 제목, 상태 배지, 액션) → 2열 grid(좌 2/3 본문 카드, 우 1/3 요약·이력) | 주문 상세, 고객 상세 |
| **대시보드** | 필터 행 → KPI 행(3–5) → 차트 grid(2–3열) → 표 | `examples/dashboard.html` |
| **설정 폼** | 좌 섹션 탭 또는 사이드바 → 폼 카드(`.ds-field` 세로 스택) → 하단 고정 저장 바 | 시스템 설정, 프로필 |
| **탐색기** | 좌 필터 패널(접힘 가능) → 상단 마킹 상태 바 → 차트 grid → 하단 상세 표/피벗 | `examples/explorer.html` |

템플릿을 벗어나는 화면은 가장 가까운 것을 복사해서 시작한다.

## 필터

- 필터는 콘텐츠 **위 한 줄** `.ds-filter-row`에 둔다. 차트 카드 안, 표 헤더 안에 두지 않는다.
- 순서: 기간 → 차원(지역, 유형) → 검색. 기간은 프리셋(오늘, 7일, 30일, 90일) 먼저, 사용자 지정은 뒤.
- 한 필터 행이 그 아래 모든 카드를 지배한다. 카드마다 다른 기간을 쓰고 싶으면 다른 페이지다.
- 적용된 필터는 칩(`.ds-chip.is-active`)으로 보이고, 하나씩 지울 수 있다.

## 반응형

| 폭 | 동작 |
|---|---|
| ≥ 1200px | 사이드바 240px 펼침, grid 3열 |
| 720–1199px | 사이드바 56px 접힘(아이콘만), grid 2열 |
| < 720px | 사이드바 숨김(헤더 햄버거), grid 1열, 필터 행 줄바꿈, 표는 `.ds-table-wrap`에서 가로 스크롤 |

- 페이지 본문은 절대 가로 스크롤이 생기지 않는다. 넓어질 수 있는 것은 표·코드·다이어그램만이고, 각자 `overflow-x: auto` 컨테이너 안에 있다.
- flex/grid 자식 중 글·표가 들어가는 것은 `min-width: 0`.
- 좌우 패딩은 `max(16px, env(safe-area-inset-*))`.

## 오버레이

| 종류 | 폭 | 용도 |
|---|---|---|
| 모달 `.ds-modal` | 480 / 640px | 확인, 짧은 폼. 중첩 금지 |
| 드로어 `.ds-drawer` | 400–560px, 우측 | 상세 보기, 긴 폼. 뒤 목록이 보여야 할 때 |
| 드롭다운 `.ds-dropdown` | 내용 폭, 최대 320px | 메뉴, 셀렉트 |
| 토스트 `.ds-toast-stack` | 360px, 우하단 | 작업 결과. 4초 후 자동 닫힘, 위험은 수동 |

숨김은 `hidden` 속성으로 한다(`el.hidden = true`). `display:none`을 직접 토글하지 않는다.
