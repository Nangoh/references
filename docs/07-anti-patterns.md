# 07. 금지 패턴

"이렇게 하면 다른 회사 시스템처럼 보인다" 또는 "읽히지 않는다" 목록. 리뷰할 때 이 목록과 대조한다. 항목마다 **왜**와 **대신**을 적었다.

## 시각 정체성

| 금지 | 왜 | 대신 |
|---|---|---|
| 크림색 배경 + 세리프 제목 + 테라코타 액센트 | 현재 AI 생성물의 대표 룩. 우리 것으로 안 읽힌다 | `--bg` + Plex + `--accent` |
| 검정 배경 + 형광 초록/주황 포인트 | 같은 이유. 다크 모드도 `--n-1000` 위에 틸이다 | 토큰 다크 모드 |
| 보라→파랑 그라데이션 히어로 | 운영 도구에 히어로가 필요 없다. 그라데이션은 어디에도 없다 | `.ds-page-header` |
| 이모지 섹션 마커·아이콘 | 플랫폼마다 모양이 다르고 정렬이 깨진다 | 16px SVG 또는 ✓ ⚠ ✕ 문자 |
| 모든 것 중앙 정렬 | 운영 화면은 왼쪽 정렬 스캔 구조다 | 좌측 정렬, 숫자만 우측 |
| 모든 블록에 큰 반경(`rounded-lg` 남발) | 둥글수록 소비자 앱처럼 보인다 | 6px, 배지 4px, 오버레이 10px |
| 카드마다 좌측 액센트 바, 카드 그림자 | 위계가 평평해지고 시끄럽다 | 테두리 1px만. 강조는 내용으로 |
| Inter·Space Grotesk·Noto Sans 임의 사용 | 글꼴이 바뀌면 다른 시스템으로 보인다 | `--font-sans` |
| 본문 16px, 컨트롤 40px 기본 | 한 화면 정보량이 줄고 모바일 앱처럼 보인다 | 14px / 32px |
| 배경에 큼직한 채도 높은 면 | 데이터보다 크롬이 크게 말한다 | 채도는 작은 마크와 액센트에만 |

## 색

| 금지 | 왜 | 대신 |
|---|---|---|
| hex·rgb·색 이름 직접 지정 (`color:#333`) | 다크 모드가 깨지고 브랜드 교체가 불가능해진다 | `var(--fg-2)` |
| `opacity`·`color-mix`로 새 색 만들기 | 검증되지 않은 색이 생긴다 | 토큰에 있는 단계 |
| 상태색을 시리즈 색으로 (`--ok`를 시리즈 3으로) | 초록 막대가 "좋음"으로 읽힌다 | `--series-n` |
| 시리즈 색으로 글자 칠하기 | 옐로·마젠타 글자는 읽히지 않는다 | 글자는 잉크 토큰, 옆에 색 점 |
| `--accent`를 일반 글자색으로 | 흰 배경 대비 3.8:1, 본문 기준 미달 | `--accent-text` 또는 `--link` |
| `--warn`을 글자색으로 | 2:1도 안 된다 | `--warn-text` |
| 라이트 값을 반전해서 다크 만들기 | 채도가 튀고 표면 위계가 뒤집힌다 | 토큰의 다크 블록 |

## 차트

| 금지 | 왜 | 대신 |
|---|---|---|
| 파이·도넛 | 가까운 값을 비교할 수 없다 | 가로 막대(순위) 또는 분할 바(비율, ≤6) |
| 이중 y축 | 두 축 정렬이 임의여서 상관관계를 발명한다 | 차트 두 개 또는 지수화(=100) |
| 3D, 그림자, 그라데이션 채움 | 값을 왜곡한다 | 평면, 단색 |
| 모든 점에 숫자 라벨 | 아무도 읽지 않고 겹친다 | 끝점·극값만, 나머지는 툴팁과 표 |
| 점선 그리드·축 | 노이즈. "예측선"으로 오해 | 1px 실선 `--chart-grid` |
| 9번째 시리즈 색 생성 | 색약에서 기존 색과 구분 불가 | `--series-other`로 접기 또는 소형 다중 |
| 필터 결과에 따라 시리즈 색 재배정 | "A는 틸"로 배운 독자를 속인다 | 색은 엔티티에 고정 |
| 명목형 범주를 값 크기로 색칠 | 막대 길이를 또 색으로 말한다 | 한 색 |
| 무지개 램프, 중앙에 색 있는 발산형 | 크기 순서가 읽히지 않는다 | `--seq-*`, `--div-*` |
| 툴팁에만 있는 값 | 키보드·터치·인쇄에서 사라진다 | 표 뷰(`tableView:true`) 또는 직접 라벨 |
| 두꺼운 막대(슬롯 가득), 두꺼운 선 | 어린아이 그림처럼 보인다 | 막대 ≤ 24px, 선 2px |
| 차트 카드 안에 기간 필터 | 카드마다 기간이 달라져 숫자가 안 맞는다 | `.ds-filter-row` 한 줄 |
| 범례 없는 다중 시리즈 | 색 맞추기 놀이 | 시리즈 2개 이상이면 범례 |
| 막대 하나짜리 막대 차트 | 숫자 하나면 차트가 아니다 | `.ds-stat` |
| 대표 숫자에 세리프·`tabular-nums` | 장식처럼 보이고 `1`이 떠 보인다 | 같은 산세리프, proportional |

## 상호작용

| 금지 | 왜 | 대신 |
|---|---|---|
| 재조회 때 스켈레톤 깜빡임 | 레이아웃이 점프한다 | 기존 내용 불투명도 0.6 유지 |
| 핀포인트 호버(8px 점을 정확히) | 못 맞춘다 | 히트 영역 24px 이상 |
| 모달 안에 모달 | 길을 잃는다 | 드로어 또는 단계형 |
| placeholder를 라벨로 | 입력하면 사라진다 | `<label for>` |
| 테두리만 빨간 오류 | 무엇이 왜 틀렸는지 모른다 | `.ds-field__error`에 원인+해결 |
| 주 버튼 여러 개 | 무엇을 눌러야 하는지 모른다 | 페이지당 하나 |
| 색만으로 상태(초록 점) | 색약·인쇄에서 사라진다 | 아이콘 + 텍스트 |
| `alert()`·`confirm()` | 스타일 불가, 일부 환경에서 안 뜬다 | `.ds-modal`, `.ds-toast` |

## 구조·코드

| 금지 | 왜 | 대신 |
|---|---|---|
| 외부 CDN `<script src="https://cdn…">` | 사내망 차단, 버전 드리프트 | `../vendor/…` |
| `ds-` 클래스 대신 새 클래스 체계 | 시스템마다 CSS가 갈라진다 | `ds.css` 확장 |
| 요소별 `margin`으로 간격 | 겹치고 두 배가 된다 | `gap` (`.ds-stack`, `.ds-row`, `.ds-grid`) |
| `display:none` 토글 | `hidden`과 충돌 | `el.hidden = true` |
| `100vh` 히어로·고정 높이 차트 컨테이너 | 축 라벨이 잘리고 중첩 스크롤이 생긴다 | 내용 높이, 축 포함 |
| 라이트 모드만 확인 | 다크에서 글자가 사라지는 사고의 대부분 | `DSTheme.toggle()` 눌러 보기 |
| 이름 없는 `<title>`("대시보드") | 탭 수십 개 중 구분 불가 | "승인 대기 · 결재 시스템" |

## 리뷰 체크리스트

제출·머지 전에 전부 체크한다.

- [ ] hex/rgb/색 이름이 코드에 없다 (`grep -nE "#[0-9a-fA-F]{3,8}\b|rgb\("`)
- [ ] `.ds-shell__header`가 있고 라이트에서도 어둡다
- [ ] 버튼·입력·표·배지·카드가 모두 `ds-` 클래스다
- [ ] 주 버튼이 페이지에 하나다
- [ ] 상태 배지·델타에 아이콘과 텍스트가 있다
- [ ] 차트에 `title`과 표 뷰(또는 직접 라벨)가 있다
- [ ] 파이·도넛·이중축·3D·점선 그리드가 없다
- [ ] 시리즈 2개 이상이면 범례가 있고, 9개 이상이면 "기타"로 접었다
- [ ] 숫자 열이 `.ds-num`이고 단위가 헤더에 있다
- [ ] 필터가 콘텐츠 위 한 줄에만 있다
- [ ] 다크 모드로 바꿔서 모든 글자가 읽힌다
- [ ] 720px에서 가로 스크롤이 없다(표는 `.ds-table-wrap` 안에서만)
- [ ] 외부 CDN 참조가 없다 (글꼴 제외)
- [ ] 이모지·그라데이션·그림자·세리프가 없다
- [ ] 폼 컨트롤에 `id`와 보이는 `label`이 있다
