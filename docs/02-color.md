# 02. 색

모든 색은 `tokens/tokens.css`에만 있다. 컴포넌트·페이지·차트는 `var(--토큰)`으로만 색을 쓴다. 이 문서의 hex 값은 참고용이며, 코드에 베끼지 않는다.

## 구조

```
원시 팔레트 (--brand-*, --n-*)      ← 브랜드를 바꿀 때 손대는 유일한 곳
   └─ 시맨틱 토큰 (--bg, --fg, --accent …)   ← 컴포넌트가 쓰는 것
   └─ 차트 토큰 (--series-*, --seq-*, --div-*, --chart-*)  ← DSCharts, ECharts 테마가 쓰는 것
상태 토큰 (--ok, --warn, --danger)    ← 의미 고정, 테마별 값만 다름
```

## 차트 범주형 8색

고정 순서. 시리즈 1부터 차례로 할당하고 순환하지 않는다. 9번째부터는 `--series-other`로 접거나 소형 다중 차트로 나눈다.

| 슬롯 | 색 | 라이트 | 다크 |
|---|---|---|---|
| `--series-1` | 틸(브랜드) | `#0091a3` | `#11a1b4` |
| `--series-2` | 오렌지 | `#e36a2e` | `#d8662a` |
| `--series-3` | 바이올렛 | `#6b5bd6` | `#8771de` |
| `--series-4` | 옐로 | `#e0a000` | `#c98500` |
| `--series-5` | 마젠타 | `#d6578e` | `#ca5e96` |
| `--series-6` | 그린 | `#3e8e1f` | `#4f9b3e` |
| `--series-7` | 블루 | `#2a78d6` | `#3986e4` |
| `--series-8` | 레드 | `#e34948` | `#da534f` |
| `--series-other` | 회색 | n-400 | n-700 |

검증 결과(`npm run validate:palette`): 라이트·다크 모두 인접 쌍 색약(protan/deutan) ΔE ≥ 10, 정상 시각 ΔE ≥ 19. 라이트 모드 옐로(`--series-4`)만 흰 표면 대비 2.3:1로 **relief 규칙**이 붙는다: 옐로가 들어가는 차트는 직접 라벨 또는 표 뷰를 반드시 함께 둔다(`DSCharts`는 `tableView:true`로 충족).

## 순차형(크기)과 발산형(극성)

| 용도 | 토큰 | 규칙 |
|---|---|---|
| 순차형 (히트맵, 지도, 크기) | `--seq-100` … `--seq-700` | 틸 한 색, 연함→진함. 100이 "거의 0". 다크에서는 앵커가 뒤집혀 100이 표면에 가까운 어두운 틸 |
| 발산형 (목표 대비, 증감) | `--div-neg-3..1`, `--div-mid`, `--div-pos-1..3` | 틸 ↔ 오렌지, 중앙은 중립 회색. 양쪽 단계 수 동일 |

무지개 램프, 중앙에 색이 있는 발산형, 두 한색(틸↔블루) 발산형은 금지.

## 차트 크롬

| 토큰 | 용도 |
|---|---|
| `--chart-surface` | 차트 바닥(카드와 동일) |
| `--chart-grid` | 그리드 1px 실선 |
| `--chart-axis` | 축선 |
| `--chart-ink` / `--chart-ink-2` / `--chart-muted` | 값 라벨 / 범례 / 축 눈금 |
| `--chart-dim` | 강조 차트에서 가라앉힌 나머지 시리즈 |
| `--chart-mark` | 마킹(선택) 하이라이트 |

차트 안의 글자는 항상 잉크 토큰을 쓴다. 시리즈 색으로 글자를 칠하지 않는다.

| 하려는 것 | 쓸 토큰 |

| 조합 | 대비 | 판정 |
|---|---|---|
| `--fg-2` on `--surface` | 6.8:1 | 본문 가능 |
| `--fg-muted` on `--surface` | 4.5:1 | 12px 캡션까지 가능 |
| `--accent` on `--surface` | 3.8:1 | 큰 글자·아이콘만. 일반 글자는 `--accent-text` |

| `--shell-fg-2` on `--shell-bg` | 7.6:1 | 셸 보조 글자 가능 |

## 다크 모드 원칙

- 같은 램프에서 따로 고른다. 라이트 값을 반전하지 않는다.
- 표면 단계는 어두운 쪽에서 올라간다: `--bg`(n-1000) < `--surface`(n-950) < `--surface-2`(n-900). 떠 있는 요소는 밝아진다.
- 그림자 대신 1px 밝은 테두리(`--shadow-*`가 다크에서 테두리로 정의됨).
- 액센트는 한 단계 밝아지고(`brand-400`), 액센트 위 글자는 어두워진다(`brand-950`).
- 셸은 더 어두워진다(`brand-950`). 셸이 본문보다 밝아지는 일은 없다.
- 차트 8색은 다크 표면용으로 다시 고른 값이며 검증을 따로 통과했다.

## 브랜드 색 교체 절차

1. `tokens/tokens.css`의 **원시 팔레트**(`--brand-50..950`)만 바꾼다. 시맨틱 토큰은 건드리지 않는다.
2. 차트 `--series-1`(라이트·다크)과 `--seq-*`, `--div-neg-*`를 새 브랜드 램프에서 고른다. OKLCH 명도 밴드: 라이트 0.43–0.77, 다크 0.48–0.67, 채도 ≥ 0.10.
3. `npm run validate:palette`를 실행해 라이트·다크 모두 PASS를 확인한다. FAIL이면 인접 슬롯의 명도를 한 단계 옮기고 다시 돈다.
4. `npm run tokens`로 `tokens.json`을 재생성하고, `npm run test`로 스크린샷을 확인한다.
