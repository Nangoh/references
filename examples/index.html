사내 시스템 공용 디자인 · 차트 레퍼런스

여러 운영 시스템이 한 팀의 것으로 보이게 하는 기준입니다. 어떤 화면을 열어도 같은 헤더, 같은 간격, 같은 차트 색이 나오도록 토큰과 컴포넌트, 차트 규칙을 한곳에 둡니다.

사람이 읽는 문서라기보다 LLM(GPT, GLM, Claude)에 그대로 먹이는 파일로 만들었습니다. 코딩 에이전트에는 AGENTS.md를, 채팅형 모델에는 prompts/system-prompt.md를 붙이면 모델이 디자인을 새로 짓지 않고 여기 정의된 클래스와 토큰만 씁니다.

  1. 색·글꼴·간격은 토큰만 쓴다tokens/tokens.css의 var(--accent) 같은 변수만. hex 직접 입력 금지. 라이트·다크는 토큰이 알아서 바꾼다.
  2. 컴포넌트는 ds.css 클래스만 쓴다버튼·입력·표·카드·배지·탭은 css/ds.css에 있다. 새 스타일을 짓지 말고 ds-btn ds-btn--primary처럼 조합한다.
  3. 차트는 ds-charts 또는 ECharts 테마간단한 차트는 js/ds-charts.js, 드릴다운·마킹이 필요하면 ECharts + integrations/echarts-theme.json. 색은 series-1~8 고정 순서.
