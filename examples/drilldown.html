계층 드릴다운 3가지 패턴

같은 계층(지역 › 지점 › 카테고리 › 제품, 매출 합계)을 세 가지 방식으로. 데이터는 examples/data/sales.csv 를 브라우저에서 집계합니다.

로딩 중

① 트리맵 — ECharts 내장 드릴

클릭하면 확대, 상단 브레드크럼(ECharts 제공)으로 복귀. 코드 최소.

② 선버스트 — 전체 계층 한 눈에

바깥 링일수록 하위 레벨. 조각 클릭 = 해당 노드를 루트로.

③ 막대 — 수동 드릴 (상태머신 + 브레드크럼)

실무에서 가장 많이 쓰는 패턴. 레벨 배열과 경로 배열만 있으면 어떤 차트에도 적용됩니다. 경로는 URL 해시에 저장되어 뒤로가기·북마크가 동작합니다.

패턴 ③ 핵심 코드

docs/08-spotfire-mapping.md 의 드릴다운 절과 같은 내용

const LEVELS = ['region', 'branch', 'category', 'product'];   // 계층 정의
const path = [];                                             // 현재 경로: ['수도권', '서울 강남']
const level = () => path.length;                             // 현재 레벨 = 경로 길이
const rowsAt = () => aggregate(LEVELS[level()], path);       // 경로로 필터 → 현재 레벨로 그룹
chart.on('click', p => { if (level() < LEVELS.length - 1) { path.push(p.name); render(); } else mark(p.name); });
function drillTo(n) { path.length = n; render(); }           // 브레드크럼 클릭 / 드릴업
function render() { chart.setOption(option(rowsAt())); breadcrumb(['전체', ...path]); location.hash = path.join('/'); }
